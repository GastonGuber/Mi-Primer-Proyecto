Español:

Maquina de café. Interfaz grafica bastante simple pero me sirvió para poder entender como funciona la programación orientada a objetos y como funciona la programación basada en eventos.

Para que se vea bien el proyecto una aclaración, en la configuración de pantalla de Windows el escalado debe estar en 100% porque sino las imágenes se ven cortadas.


Ingles:

Coffee machine. The graphical interface is quite simple, but it helped me understand how object-oriented programming and event-driven programming work.

To ensure the project looks good, please note that in Windows display settings, the scaling must be set to 100%, otherwise the images will appear cropped.
